---
name: implement
description: "Implement a piece of work based on a spec or set of tickets."
---

Implement the work described by the user in the spec or tickets.

Read `../tdd/SKILL.md` and use TDD where meaningful, at public boundaries agreed in the feature spec. Do not add tests for low-impact documentation or styling changes merely to follow the workflow.

Run typechecking regularly, single test files regularly, and the full test suite once at the end.

Once done, read `../code-review/SKILL.md` and review the work, including uncommitted changes, against the agreed spec and repository standards.

Report the result and validation. Commit only when the user has requested or authorized a commit; installation or implementation alone does not imply pushing or merging.
